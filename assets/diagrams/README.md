# Diagrams

Store editable diagram sources and exports here. Prefer source formats that can be revised later (SVG, Mermaid `.mmd`, or Excalidraw `.excalidraw`) rather than only raster screenshots.

Suggested naming: `<concept-slug>.<source-extension>`.

In the relevant concept article, add alt text and a relative link to the diagram. A diagram should clarify an execution flow, data layout, protocol roles, or system boundary—not exist only for decoration.

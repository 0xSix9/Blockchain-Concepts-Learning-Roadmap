# Code of Conduct

## Our commitment

This project aims to be a respectful place to learn and discuss blockchain engineering. Participants are expected to be welcoming, constructive, and considerate.

## Expected behavior

- Be respectful of different backgrounds and levels of experience.
- Critique technical ideas and evidence, not people.
- Explain corrections clearly and provide sources when possible.
- Accept good-faith feedback and acknowledge uncertainty.
- Avoid harassment, insults, discrimination, and personal attacks.

Project maintainers may edit, decline, or remove contributions that do not follow these standards. For concerns, contact the repository owner through the GitHub profile linked in the README.

# Security Policy

This repository is an educational documentation project, not an official vulnerability disclosure channel for Ethereum, Solidity, clients, or third-party protocols.

For inaccurate or potentially misleading documentation, open an issue with the file or section, a description of the problem, and supporting references.

Do not post sensitive exploit details in a public issue. For a real vulnerability, use the affected project's official security disclosure process or bug bounty program.

Educational examples are not security audits and should not be assumed safe for production.
